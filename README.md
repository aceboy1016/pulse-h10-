# PULSE

POLAR H10 などの心拍計から Web Bluetooth で心拍数を受信し、パーソナルトレーニング中に大きな画面へ表示するツールです。
静的な HTML / CSS / JavaScript のみで動作し、外部への通信・アクセス解析・外部フォントはありません。

## 使い方

1. Mac の Google Chrome で公開URLを開く（Safari・Firefox は Web Bluetooth 非対応）。
2. 「H10に接続」を押し、一覧から Polar H10 を選択する（電極を湿らせて装着しておく）。
3. **運動前**：顧客を選択（または「新規」で登録）し、落ち着いた状態で「現在値を登録」→「運動を開始」。
4. **運動中**：現在心拍・最大心拍に対する割合・強度の目安を表示。セットが終わったら「セット終了・回復を測る」。
5. **回復**：回復方法・種目・重量・回数を入力。60秒値が確定したら「記録して終了」で運動中に戻る。
6. 最後に「セッション終了」で **結果** に移り、履歴・比較・CSV出力ができます。

「デモ」ボタンは実測ではない模擬信号です。デモの記録は「デモ」と区別して保存され、実測とは比較しません。

## 計測の取り決め

- 心拍値：Heart Rate Service `0x180D` / Heart Rate Measurement `0x2A37`。Flags の bit0 で 8bit / 16bit を判定。センサー接触なしの値は記録しない。
- 受信が 5 秒以上途絶えたら現在値を `--` 表示にし、グラフも欠測区間をつながない。
- 推定最大心拍：208 − 0.7 × 年齢（Tanaka et al., 2001）。測定済みの最大心拍を優先する設定あり。
- 強度の目安：ACSM の %HRmax 分類（Garber et al., 2011）。<57% とても軽い／57–63% 軽い／64–76% 中等度／77–95% 高い／96%以上 最大に近い。生理学的な閾値（乳酸閾値・換気閾値）とは別物。
- 回復：開始時心拍はボタン押下前 2 秒以内の実測値。30・60・120 秒値は目標時刻 ±2 秒以内で最も近い実測値。範囲内に実測がなければ「測定不足」、途中に 5 秒以上の欠測・切断・接触なしがあれば「欠測あり」とし比較に使わない。
- 比較：同じ顧客・同じ入力源（実測/デモ）・同じ回復方法・同じ種目。重量と回数まで一致した場合のみ「同条件」と表示。

心拍の低下は心拍の回復であり、筋肉の回復・乳酸の除去・次セットの可否を示すものではありません。

## データ

- 保存先はこのブラウザの IndexedDB（データベース名 `pulse-h10`）。サーバーや GitHub には送信しません。
- 「結果」→「データ管理」から JSON バックアップ／復元、CSV 出力ができます。復元は既存データを削除せず追加のみ（同じIDはスキップ）。
- 旧サイト（localStorage キー `pulse-v2`）のデータは、ドメインが違うため自動では移行できません。旧サイトでバックアップを書き出すか、旧サイトを開いた Chrome の DevTools コンソールで `copy(localStorage.getItem('pulse-v2'))` を実行し、内容を `.json` ファイルに保存してから「JSONから復元」で読み込んでください。旧形式は実データで未確認のため、よくある形を幅広く受け付ける変換にしています。

## 開発

```sh
node tests/physio.test.js     # 心拍解析・回復計算・バックアップ検証のテスト
python3 -m http.server 8000   # http://localhost:8000/ で確認（localhost は Web Bluetooth 可）
```
